Research Question & Motivation

Research Question:

Given environmental conditions (weather, lighting, road surface, speed limit) and traffic unit characteristics (TU type, manoeuvre, number of units), can we predict NSW road crash severity (Fatal / Injury / Non-casualty)? — A three-class classification problem.

Motivation:

  • NSW recorded 340 road fatalities in 2024, over two-thirds in regional areas (TfNSW, 2025)
  • Fatal crashes represent only ~1.4% of all crashes → severe class imbalance
  • A predictive model has direct value for:
Stakeholder Value
Traffic Authorities Targeted speed and road interventions
Emergency Responders Faster, evidence-based resource allocation
Policymakers & Insurers Precise policy and pricing decisions

Data Preprocessing: Pipeline

Rubric criterion: Data Preprocessing  |  2 pts

Steps 1–5: Cleaning & Feature Engineering

  1. TU Integration — aggregated traffic-unit flags per crash (has_motorcycle, has_heavy_vehicle, has_pedestrian, has_cyclist) using group_by + summarise + left_join
  2. Feature removal — dropped leakage columns (post-crash injury counts), identifiers, and variables with >75% missing values; dropped Degree of crash - detailed (redundant with target)
  3. Imputation — removed rows >50% missing; categorical → "Unknown"; numeric → median
  4. Feature engineering — is_weekend, is_rush_hour, is_night, is_wet, speed bands — all motivated by EDA findings
  5. Outlier handling — NSW geographic bounds filter; winsorise Distance at 99th percentile

Steps 6–9: Modelling Setup

  1. Encoding — trees use native R factor; KNN/LR use one-hot; rare LGA levels → "Other"
  2. Scaling — Z-score standardisation within fold for KNN; trees are scale-invariant
  3. Class imbalance — inverse-frequency class weights (all models); SMOTE applied inside training fold only
  4. Split — 2024 data sealed as temporal holdout; 80/20 stratified split on 2020–2023; 5-fold CV

Data Preprocessing: Feature Engineering & Class Balancing

Rubric criterion: Data Preprocessing  |  2 pts

Engineered features — all motivated by EDA

Feature Derivation EDA motivation
speed_band Cut Speed limit into ≤50 / 60–80 / 90–100 / 110 Fatal rate rises sharply above 100 km/h
is_night Natural lighting ∈ {Darkness, Dawn, Dusk} Dark conditions double fatal risk
is_rush_hour Two-hour intervals ∈ {7–9, 16–18} Commute peaks dominate crash volume
is_weekend Day of week of crash ∈ Saturday, Sunday Weekend crashes differ in severity profile
is_wet Surface condition contains “Wet” Wet roads linked to skidding fatalities
has_motorcycle TU-level aggregated flag Motorcyclists over-represented in fatals
has_pedestrian TU-level aggregated flag Pedestrian crashes nearly always severe

Handling class imbalance

  • Raw Fatal share ~1.4% → accuracy-maximising models ignore Fatal entirely
  • Strategy: inverse-frequency class weights (all models) + SMOTE inside training fold (LR, KNN)
  • SMOTE raises synthetic Fatal share to ~10% in training only — test set remains unmodified
